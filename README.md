#### 1. Baixar o git no computador
<a href="https://git-scm.com/downloads">Link para baixar o git</a>


#### 2. Clonar o repositório: 
Rode o seguinte comando em algum terminal:
```bash
    git clone https://github.com/juannxyz/portfolio-targa
```

#### 3. Como enviar as alterações ao github:

```bash

git fetch
git checkout -b <sua-branch>
git add .
git commit -m "<mensagem>"
git push origin <sua-branch>

```

Explicação dos comandos:

**git fetch** - Se seu projeto estiver desatualizado e não conseguir acessar alguma branch ou algo semelhante, rode esse comando.

**git checkout** - Serve para mudar de branch

**git checkout -b** - Serve para mudar de branch caso ela não exista

**git add .** - Serve para selecionar os arquivos do commit

**git commit -m "\<mensagem\>"** - Serve para criar o commit no seu computador

**git push origin \<sua-branch\>** - Envia seus commits para o github
